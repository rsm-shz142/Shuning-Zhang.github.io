Does Raising the Minimum Wage Kill Jobs? Replicating Card & Krueger (1994)

A Difference-in-Differences Study of Fast-Food Employment in New Jersey and Pennsylvania

Economics
Python
Causal Inference
Difference-in-Differences
Replicating the landmark Card & Krueger (1994) paper using difference-in-differences to show that New Jersey’s minimum wage increase did not reduce fast-food employment.
Author

Jiahui Huang

Published

April 22, 2025

Introduction

Does raising the minimum wage reduce employment? Standard economics textbooks say yes — if you force wages above the market-clearing level, employers will hire fewer workers. But a landmark 1994 study by economists David Card and Alan Krueger (who later won the Nobel Prize) challenged this prediction head-on.

Their key insight was to use New Jersey and Pennsylvania as a natural experiment. On April 1, 1992, New Jersey raised its minimum wage from $4.25 to $5.05 per hour — the highest state minimum wage in the country at the time. Pennsylvania kept its minimum wage unchanged. Both states share a border and similar economies, making Pennsylvania a natural “control group” for what would have happened to New Jersey’s employment without the wage hike.

Card and Krueger surveyed 410 fast-food restaurants (Burger King, KFC, Wendy’s, and Roy Rogers) in both states before the increase (February–March 1992) and after (November–December 1992). By comparing how employment changed in New Jersey relative to Pennsylvania, they could isolate the causal effect of the minimum wage — a method known as difference-in-differences (DiD).

Their finding was striking: employment did not fall in New Jersey. If anything, it rose slightly. This paper replicates their core results.

# ── Construct key variables (following Card & Krueger's SAS code) ──────────
# Full-time equivalent employment = full-time + 0.5×part-time + managers
df['emptot']  = df['empft']  + 0.5 * df['emppt']  + df['nmgrs']
df['emptot2'] = df['empft2'] + 0.5 * df['emppt2'] + df['nmgrs2']

# Permanently closed stores (status2 == 3) get wave-2 employment = 0
df.loc[df['status2'] == 3, 'emptot2'] = 0.0

# NJ indicator (1 = New Jersey, 0 = Pennsylvania)
df['nj'] = df['state']

# Change in employment
df['demp'] = df['emptot2'] - df['emptot']

# GAP variable: how much each NJ store needed to raise wages
# GAP = 0 for PA stores and NJ stores already above $5.05
# GAP = (5.05 - wage_st) / wage_st for affected NJ stores
df['gap'] = 0.0
mask_affected = (df['nj'] == 1) & (df['wage_st'] < 5.05) & (df['wage_st'].notna())
df.loc[mask_affected, 'gap'] = (5.05 - df.loc[mask_affected, 'wage_st']) / df.loc[mask_affected, 'wage_st']

# Chain dummies
df['bk']   = (df['chain'] == 1).astype(int)
df['kfc']  = (df['chain'] == 2).astype(int)
df['roys'] = (df['chain'] == 3).astype(int)

# Balanced sample: valid employment data in both waves
balanced = df[df['emptot'].notna() & df['emptot2'].notna() &
              df['wage_st'].notna() & df['wage_st2'].notna()].copy()

Replication: Table 2 — Key Variable Means

Before diving into the DiD, we check that the two groups (NJ and PA) looked similar at baseline — an important validity check. The table below mirrors Table 2 from the paper.

Code 
def mean_se(series):
    m = series.mean()
    se = series.sem()
    return f"{m:.2f} ({se:.2f})"

nj = df[df['nj'] == 1]
pa = df[df['nj'] == 0]

rows = {
    'FTE employment — Wave 1': ('emptot',  nj, pa),
    'FTE employment — Wave 2': ('emptot2', nj, pa),
    'Starting wage — Wave 1':  ('wage_st', nj, pa),
    'Starting wage — Wave 2':  ('wage_st2',nj, pa),
}

table2_data = []
for label, (var, nj_df, pa_df) in rows.items():
    nj_val = nj_df[var].dropna()
    pa_val = pa_df[var].dropna()
    t_stat, p_val = stats.ttest_ind(nj_val, pa_val, nan_policy='omit')
    table2_data.append({
        'Variable': label,
        'NJ': f"{nj_val.mean():.2f} ({nj_val.sem():.2f})",
        'PA': f"{pa_val.mean():.2f} ({pa_val.sem():.2f})",
        't-stat': f"{t_stat:.1f}"
    })

table2 = pd.DataFrame(table2_data).set_index('Variable')
table2.index.name = None
table2.columns.name = None
print(table2.to_string())

This is the heart of the paper. We compare employment changes in New Jersey vs. Pennsylvania.

The DiD estimate of +2.75 FTE employees almost exactly matches the paper’s +2.76. Pennsylvania stores lost about 2.3 workers on average while New Jersey stores barely changed — a difference that is statistically significant (t ≈ 2.0).

Replication: Table 4 Col (i) — Regression-Adjusted DiD

The DiD can also be estimated by regressing the change in employment on a New Jersey dummy. This allows us to add controls for chain type.

Code 
# ── Table 4 regressions ────────────────────────────────────────────────────
reg_df = df[df['demp'].notna() & df['wage_st'].notna() & df['wage_st2'].notna()].copy()
reg_df['bk']   = (reg_df['chain'] == 1).astype(int)
reg_df['kfc']  = (reg_df['chain'] == 2).astype(int)
reg_df['roys'] = (reg_df['chain'] == 3).astype(int)

# Col (i): NJ dummy only
m1 = smf.ols('demp ~ nj', data=reg_df).fit()

# Col (ii): NJ dummy + chain/ownership controls
m2 = smf.ols('demp ~ nj + bk + kfc + roys + co_owned', data=reg_df).fit()

print("TABLE 4 — Regression of ΔEmployment on NJ dummy")
print("─" * 55)
print(f"{'Model':35s} {'NJ coeff':>10} {'SE':>8}")
print("─" * 55)

The coefficient on the NJ dummy (+2.28) is very close to the paper’s +2.33. The small difference comes from a slightly different sample restriction. Adding chain-type controls (Burger King, KFC, Roy Rogers, company-owned) has essentially no effect — the result is robust.

Why Does This Study Support Causal Claims?

The difference-in-differences design is compelling here for several reasons:

1. A clean control group. Pennsylvania and New Jersey share a border, similar demographics, and the same fast-food chains. Any economic shocks hitting the region (like the 1992 recession) affected both states similarly.

2. Pre-treatment comparability. As Table 2 shows, NJ and PA stores had nearly identical starting wages ($4.61 vs. $4.63) and similar employment levels before the policy. The DiD assumption — that the two groups would have moved in parallel absent the minimum wage change — is credible.

3. The policy was plausibly exogenous. The $5.05 minimum had been legislated in 1989, well before the 1992 recession, so it wasn’t a response to current economic conditions. The timing was determined by politics, not by the labor market.

4. Internal validation. As a specification test, the authors show that high-wage NJ stores (already paying ≥$5.00) — which were unaffected by the law — behaved like Pennsylvania stores. Only the low-wage NJ stores saw employment gains, exactly as expected if the minimum wage was the driver.

Conclusion

This replication confirms Card and Krueger’s central finding: New Jersey’s 19% minimum wage increase did not reduce fast-food employment. The difference-in-differences estimate of approximately +2.75 FTE employees per store is precisely reproduced from the original data.

The result contradicts the simple competitive model but is consistent with monopsony-like labor markets, where employers have wage-setting power. When a minimum wage forces employers to pay more, they may actually attract more workers and expand employment — at least over moderate ranges of the minimum wage.

Card and Krueger’s paper sparked decades of follow-up research and helped shift how economists think about minimum wages. David Card was awarded the Nobel Prize in Economics in 2021, in part for this line of work.
